# swan_sync
SWAN Sync - Sync with asynchronous negotiation, a free synchronization framework.

The main branch contains the module itself. It can be forked/downloaded locally or referenced via the url parameter in your `pubspec.yaml`:

```yaml
  swan_sync:
    git:
      url: https://github.com/jfletcher20/swan_sync.git
      ref: main
```


See [the corresponding example branch on this repository](https://github.com/jfletcher20/swan_sync/tree/example/SWAN-Sync) for an example solution integration.
